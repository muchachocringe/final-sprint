Директрия `pkg` содежит основые пакеты
`main.go` - Инициализирует БД и запускает сервер
`pkg/db/` - Работа с SQLite базой данных
`pkg/api/` - REST API endpoints для операций с задачами
`pkg/server/` - Конфигурация и запуск HTTP сервера

Локальный запуск на порту:
`http://localhost:7540`

Тесты:
`go test -run ^TestApp$ ./tests` - тест веб файлов
`go test -run ^TestDB$ ./tests` - тест работы с БД
`go test -run ^TestNextDate$ ./tests` - тест расчета дат
`go test -run ^TestAddTask$ ./tests` - добавления задач
`go test -run ^TestTasks$ ./tests` - получение списка задач
`go test -run ^TestEditTask$ ./tests` - тест редактирования задач
`go test ./tests` - тест общего функционала

Вынес константу для api в отдельный пакет `consts`
